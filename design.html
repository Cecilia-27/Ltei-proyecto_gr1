Paleta de colores

el color como lenguaje de identidad

El color funciona para jerarquizar, navegar y llamar la atención. Rojo corazón: marca, CTA principal. Azul creativo: secundario, acciones complementarias. Turquesa: gráfico, never text.

Rojo corazón
CTA principal, títulos, marcas, navegación activa
Azul creativo
Subtítulos, enlaces secundarios, botones secundarios, etiquetas
Turquesa
SOLO gráfico: hover, indicadores, separadores. NUNCA texto.
Verde muy claro
Fondo base predominante, secciones principales
Blanco
Tarjetas, campos, contenedores, superficies
Negro
Texto principal, navegación, máximo contraste

Reglas

lo que sí y lo que no

El diseño se basa en experimentación controlada y composiciones asimétricas. Estas reglas mantienen la identidad visual coherente.

✗ Colores fuera de paleta
Nunca usar colores no definidos en el sistema de diseño.
✗ Sombras y animaciones
Evitar sombras pesadas o animaciones excesivas.
✗ Tipografías decorativas
No usar fuentes que dificulten la lectura.
✗ Sacrificar legibilidad
La experimentación nunca debe comprometer la lectura.
✗ Todo redondeado
No convertir todos los elementos en formas redondeadas.
✗ Turquesa dominante
Nunca usar turquesa como color dominante o como texto.
